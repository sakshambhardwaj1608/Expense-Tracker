A simple Python-based Expense Tracker for recording and managing daily expenses.

Features
Add daily expenses
View all expenses
Calculate total expenses
Store expense information in a text file
Technologies Used
Python
File Handling
Basic Python Data Processing
Expense Information

The program stores:

Date
Category
Amount
Description
How to Run
Download or clone the project.
Make sure Python is installed on your computer.
Open the project folder in VS Code or another Python editor.
Run the Python file:
python expense_tracker.py

Select an option from the menu.
File Handling

The program uses expenses.txt to store expense records. Each expense is saved with its date, category, amount, and description.
